Yahoo 리그 로스터 가져오기

Yahoo에 로그인된 브라우저 안에서 10팀 로스터·선발/벤치·매치업·순위를 읽어 rosters.json 파일로 저장하는 버튼이에요. 로그인 정보는 브라우저 밖으로 나가지 않아요.

1. 버튼 설치 (PC, 한 번만)

북마크바가 안 보이면 Ctrl+Shift+B를 누르세요. 아래 보라색 버튼을 북마크바로 끌어다 놓으면 설치 끝이에요.

🏈 NFL 로스터 가져오기 준비 중…

끌어다 놓기가 안 되면: 아무 페이지나 북마크 추가 → 북마크 편집 → URL 칸에 아래 코드 복사한 내용을 붙여넣기.

2. 사용 방법

  1. Yahoo Fantasy에 로그인하고 리그 홈 화면을 여세요.
    예: football.fantasysports.yahoo.com/f1/1430993
  2. 북마크바의 🏈 NFL 로스터 가져오기를 누르세요. 오른쪽 위 검은 상자에 진행 상황이 보이고, 30초~1분 뒤 완료!가 나와요.
  3. 검은 상자의 ① 📋 데이터 복사를 누르세요. 옆에 복사됨 ✓이 보이면 돼요.
  4. ② GitHub 편집 화면 열기를 누르세요 (GitHub에 sirius4lee-dot 계정으로 로그인돼 있어야 해요).
  5. 열린 화면의 큰 글상자를 클릭 → Ctrl+A (전체 선택) → Ctrl+V (붙여넣기).
  6. 오른쪽 위 초록색 Commit changes… → 나오는 창에서 다시 Commit changes. 1~2분 뒤 모든 기기의 기록장에 반영돼요.

트레이드·웨이버가 있었거나 한 주가 끝났을 때 다시 누르면 돼요. 선수 Fan Pts는 기록장의 ‘업데이트’ 버튼이 따로 최신으로 유지해요.

버튼을 눌러도 아무 반응이 없을 때 (콘솔로 실행)

  1. 아래 콘솔용 코드 복사를 누르세요.
  2. Yahoo 리그 홈에서 F12 → 위쪽 Console(콘솔) 탭을 여세요.
  3. 처음 한 번은 붙여넣기가 막혀 있어요. 입력줄에 allow pasting 을 직접 타이핑하고 Enter.
  4. Ctrl+V로 코드를 붙여넣고 Enter. 오른쪽 위에 검은 진행 상자가 나타나요.

폰에서만 쓸 때

모바일 브라우저는 북마크 설치가 번거로워요. 로스터 가져오기는 PC에서 하고 GitHub에 올리면, 폰에서는 기록장을 열기만 하면 돼요.

Yahoo 리그 로스터 가져오기

Yahoo에 로그인된 브라우저 안에서 10팀 로스터·선발/벤치·매치업·순위를 읽어 기록장에 올리는 북마크 버튼이에요. Yahoo 로그인 정보는 브라우저 밖으로 나가지 않아요.

1. 자동 올리기 버튼 만들기 (추천, 한 번만)

버튼 한 번에 Yahoo 읽기 → GitHub 올리기 → 커밋까지 끝나요. 이 저장소에만 쓸 수 있는 GitHub 토큰이 필요해요.

  1. GitHub 토큰 만들기 화면 열기 ↗ (sirius4lee-dot 계정으로 로그인)
  2. Token name: nfl-roster · Expiration: 366 days (1년 뒤 다시 만들면 돼요)
  3. Repository access: Only select repositories → nfl-fantasy 선택
  4. Permissions → Repository permissions → Contents를 Read and write로
  5. 맨 아래 Generate token → 나온 github_pat_… 를 복사
  6. 아래 칸에 붙여넣고 확인하고 버튼 만들기

    토큰은 이 페이지에 저장되지 않고, 만들어지는 북마크 버튼 안에만 들어가요.

  7. 북마크바의 예전 버튼은 지우고, 이 버튼을 북마크바로 끌어다 놓으세요:
    🏈 NFL 로스터 올리기

⚠ 이 버튼(북마크)은 다른 사람과 공유하지 마세요. 안에 토큰이 들어 있어요. 토큰이 유출돼도 이 저장소의 파일만 바꿀 수 있고, 걱정되면 GitHub 설정에서 언제든 삭제할 수 있어요.

2. 사용 방법

  1. Yahoo Fantasy에 로그인하고 리그 홈을 여세요. (football.fantasysports.yahoo.com/f1/1430993)
  2. 북마크바의 🏈 NFL 로스터 올리기를 누르세요.
  3. 오른쪽 위 검은 상자에 GitHub에 자동으로 올리고 커밋했어요 ✓가 나오면 끝. 1~2분 뒤 모든 기기의 기록장에 반영돼요.

자동 올리기가 실패하면 검은 상자에 이유와 함께 수동 방법(데이터 복사 → GitHub 편집 화면에 붙여넣기)이 나와요. 한 주가 끝났을 때나 트레이드·웨이버 뒤에 누르면 돼요. 누를 때마다 1주차부터 현재 주차까지 전부 다시 읽어요.
